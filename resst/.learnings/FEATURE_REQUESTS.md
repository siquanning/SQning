# 功能需求记录

用于记录用户提出但当前尚不具备的能力或功能。

**领域**：前端｜后端｜基础设施｜测试｜文档｜配置  
**状态**：待处理｜处理中｜已解决｜不处理  
**复杂度**：简单｜中等｜复杂

## 状态说明

| 状态 | 含义 |
|---|---|
| `待处理` | 尚未处理 |
| `处理中` | 正在实现 |
| `已解决` | 功能已经实现，并附有解决说明 |
| `不处理` | 决定不实现，并在解决说明中写明原因 |

## 记录格式

```markdown
## [FEAT-年月日-序号] 功能名称

**记录时间**：ISO 8601 时间
**优先级**：低｜中｜高｜紧急
**状态**：待处理
**领域**：前端｜后端｜基础设施｜测试｜文档｜配置

### 所需能力
说明用户希望具备什么能力。

### 用户背景
说明用户为什么需要它，以及它要解决什么问题。

### 复杂度估计
简单｜中等｜复杂

### 建议实现
说明可能的实现方式以及可以复用或扩展的现有能力。

### 元数据
- 出现频率：首次｜重复
- 相关功能：现有功能名称（没有则省略）

---
```

除命令、代码、路径、产品名和标准编号外，记录内容必须使用简体中文。
