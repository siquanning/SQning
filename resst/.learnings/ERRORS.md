# 错误记录

用于记录开发过程中出现的命令失败、接口错误和非预期行为。

**领域**：前端｜后端｜基础设施｜测试｜文档｜配置  
**状态**：待处理｜处理中｜已解决｜不处理｜已晋升｜已晋升为技能

## 状态说明

| 状态 | 含义 |
|---|---|
| `待处理` | 尚未处理 |
| `处理中` | 正在处理 |
| `已解决` | 问题已解决，并附有解决说明 |
| `不处理` | 决定不处理，并在解决说明中写明原因 |
| `已晋升` | 已提炼到长期规则文件 |
| `已晋升为技能` | 已提炼为可复用技能 |

## 记录格式

```markdown
## [ERR-年月日-序号] 错误名称

**记录时间**：ISO 8601 时间
**优先级**：低｜中｜高｜紧急
**状态**：待处理
**领域**：前端｜后端｜基础设施｜测试｜文档｜配置

### 摘要
简要说明出现了什么错误。

### 错误信息
粘贴实际错误信息或输出；原始英文报错可保留，并补充中文解释。

### 发生背景
- 尝试执行的命令或操作
- 使用的输入或参数
- 相关环境信息

### 建议修复
说明可能的修复方法。

### 元数据
- 可复现：是｜否｜未知
- 相关文件：文件路径
- 相关记录：相关记录编号（没有则省略）

---
```

除原始报错、命令、代码、路径、产品名和标准编号外，记录内容必须使用简体中文。
