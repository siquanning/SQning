# 杭州麻将 (Hangzhou Mahjong)

单人对抗三位 AI 的杭州麻将浏览器游戏，纯前端实现。

## 快速开始

用浏览器打开 `src/index.html` 即可开始游戏。

## 玩法规则

- **白板财神**：白板作为万能牌（财神），可替代任意牌组成牌型
- 支持吃、碰、明杠、暗杠
- **飘财**：听牌后可亮出财神，胡牌得分翻倍
- 胡牌牌型：平胡、七对、爆头、杠开、飘财
- 纯自摸规则（无点炮）

## 操作

- **出牌**：鼠标上推手牌，或选中手牌后按 `D` 键
- **飘财**：听牌时出现"飘财"按钮，点击后亮财神等胡
- **吃碰杠胡**：回合出现时点击按钮，或按数字键 `1-4` 选择，空格跳过
- **新局**：点击 ↻ 按钮

## 技术栈

- Vanilla JS（无框架）
- CSS 3D 变换桌面透视效果
- Web Audio API 合成音效
- localStorage 自动存档
- 启发式 AI（搭子识别 + 听牌质量评估 + 防守意识）
