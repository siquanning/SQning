# 参考资料 (Reference) | NSQ

> 存放本项目用到的外部参考资料，按类别分四个子目录。这些文件**不参与编译**，仅供开发时查阅。

---

## 目录说明

| 子目录 | 用途 | 典型文件 |
|---|---|---|
| `schematics/` | 原理图、PCB 图、接线图 | `.pdf`、`.png`、`.sch`、`.pcb` |
| `code/` | 可供参考的代码片段或示例工程 | `.c`、`.h`、`.zip` |
| `projects/` | 相关项目文件（如上级/下级项目输出） | `.md`、`.xlsx`、`.txt` |
| `datasheets/` | 芯片数据手册、应用笔记 | `.pdf`（从 TI/厂商官网下载） |

---

## 使用建议

- 原理图放在 `schematics/` 下，按版本号命名（如 `schematic_v2.1.pdf`）
- 参考代码放入 `code/` 时，建议在文件名中标注来源和日期
- 数据手册建议用芯片型号命名（如 `TMS320F28335.pdf`）
- 大文件（>1MB）考虑加入 `.gitignore`，改用外部链接索引
