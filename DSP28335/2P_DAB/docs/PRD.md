# 2P_DAB 产品需求文档 (PRD)

## 1. 项目概述

基于 TI TMS320F28335 的双有源桥（DAB）电源控制系统，实现 DPS（双移相）调制，通过 Modbus RTU 通信实现远程监控与控制。

## 2. 硬件规格

| 参数 | 数值 |
|------|------|
| 原边直流电压 V1 | 400V（固定，不采样） |
| 副边直流电压 V2 | 100V（额定） |
| 变压器匝比 n | Np/Ns = 4 (k=V1/(n·V2)=1 @V2=100V) |
| 额定功率 | ~667W |
| 负载 | 15Ω |
| 开关频率 | 10kHz |
| MCU | TMS320F28335 @ 150MHz |

## 3. 控制架构

### 3.1 总体框图

```
                         ┌──────────────────────────────────┐
                         │ k = V1 / (n · V2)  (电压变比)     │
                         │ V1=400V 固定, n=Np/Ns 为变压器匝比  │
                         └───────────────┬──────────────────┘
                                         │ k
                                         ▼
V2_ref ─→ [斜坡] ─→ [Σ] ─→ [PID] ─→ p0 ─→ [C-Script DPS] ─→ D1,D2 ─→ [ePWM×4] ─→ DAB功率级
                      ↑                                           
                     V2 ←── [IIR滤波] ←── [ADC] ←── V2(输出电压)
```

**信号流说明：**
1. ADC 采集输出电压 V2 → IIR 低通滤波
2. 滤波后的 V2 与斜坡后的 V2_ref 比较 → 误差送入 PID
3. PID 输出 **p0**（归一化功率指令 [0, 1]）
4. 同时计算电压变比 **k = V1 / (n · V2)**，其中 V1=400V（固定），n = Np/Ns 为变压器匝比
5. p0 和 k 共同输入 **C-Script DPS 调制算法**，输出 **D1**（桥间移相比）和 **D2**（桥内移相比）
6. D1/D2 映射到 ePWM 模块间的相位关系，产生 8 路 PWM 驱动 DAB 功率级

### 3.2 控制参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 控制频率 | 1kHz | 与 1ms systick 同步 |
| PID Kp | 1.0 | 比例系数 |
| PID Ki | 0.1 | 积分系数 |
| PID Kd | 1.0 | 微分系数 |
| PID 输出限幅 | [0, 0.999] | 归一化功率 p0 |
| 反馈滤波器 | 一阶 IIR 低通 | fc ≈ 100Hz |

### 3.3 DPS 调制算法 (compute_D1_D2)

移植自 PLECS 仿真 `dab_test.plecs` 中的 C-Script 算法，参考代码见 `assets/reference/dps_cscript_algorithm.c`。

- **输入**: p0（归一化功率指令 [0, 1]，来自 PID），k（电压转换比 = V1/(n·V2)）
- **输出**: D1（桥间移相比 [0, 1]），D2（桥内移相比 [0, 1]）
- **计算周期**: 每个控制周期（1kHz）计算一次，写入 ePWM 影子寄存器

**分区策略**（三段区域，最小化 RMS 电流）：

| 区域 | 条件 | 说明 |
|------|------|------|
| 1 — 高功率 | p0 ∈ [2/3, 1] | 直接计算，k≥1 和 k<1 对称处理 |
| 2 — 低功率 k<1 | p0 < 2/3, k ∈ (bound1_L, bound1_H) | 中间区域，使用 term1/term2 公式 |
| 3 — 低功率 k≥1 | p0 < 2/3, k ∈ (bound2_L, bound2_H) | 中间区域，对称于区域2 |
| 兜底 | 不在上述区间 | 回退到高功率逻辑 |

边界值计算：`bound1_L/H = (1 ± sqrt(max(0, 4-6p0))) / 3`，`bound2_L/H = 3 / (1 ± sqrt(max(0, 4-6p0)))`

### 3.4 PWM 调制信号链路 (compute_modulation_signals → carrier → PWM)

完整调制链路参考代码见 `assets/reference/dab_full_modulation_chain.c`。

**Step 1: D1,D2 → 调制波 (SD1, SD2, ST)**

```
SD1 = 0.5 * (1.0 + D1)    范围 [0.5, 1.0] — 原边移相调制波
SD2 = 0.5 * D2            范围 [0.0, 0.5] — 副边基本调制波
ST  = SD1 + SD2           范围 [0.5, 1.5] — 副边叠加调制波
```

**Step 2: 三角载波生成**

- 类型：对称三角波 (DutyCycle=1)，模拟 PLECS TriangleGenerator
- 范围：[0, 1]，频率：10kHz，周期 Tsw = 100us
- 对应 ePWM 时基计数器的递增-递减模式 (TB_COUNT_UPDOWN)

**Step 3: PWM 比较逻辑 (4 路 RelationalOperator, ≥ 模式)**

| 比较式 | 驱动主开关 | 互补开关 | 说明 |
|--------|-----------|----------|------|
| carrier ≥ 0.5 | S1 | S2 (NOT) | 原边左半桥，50% 固定占空比方波 |
| \|SD1 − carrier\| ≥ 0.5 | S3 | S4 (NOT) | 原边右半桥，D1 控制移相 |
| \|SD2 − carrier\| ≥ 0.5 | Q1 | Q2 (NOT) | 副边左半桥，D2 控制移相 |
| \|ST − carrier\| ≥ 0.5 | Q3 | Q4 (NOT) | 副边右半桥，ST 叠加控制 |

**Step 4: 死区插入**

- 逻辑：上升沿延迟 Td_on，下降沿**立即**关断（与 PLECS BlankingTime 模块一致）
- 仅对主开关插入死区，互补信号由 NOT 生成（自动包含死区对称性）
- ePWM 硬件实现：使用 DB（死区）模块，默认 200ns

**Step 5: 单步整体函数 (`dab_pwm_step`)**

每个仿真步长调用一次：读取 t/dt/D1/D2 → 计算载波 → 比较 → 死区 → 输出 8 路门极信号。

## 4. PWM 配置

| ePWM 模块 | 引脚 | 驱动开关 | 说明 |
|-----------|------|----------|------|
| ePWM1 | GPIO00/01 | S1/S2 | 原边左半桥（互补+死区） |
| ePWM2 | GPIO02/03 | S3/S4 | 原边右半桥（互补+死区） |
| ePWM3 | GPIO04/05 | Q1/Q2 | 副边左半桥（互补+死区） |
| ePWM4 | GPIO06/07 | Q3/Q4 | 副边右半桥（互补+死区） |

- 引脚来源：PZ-DSP28335-L 底板原理图，28335 controlCARD DIMM-100，已确认无冲突
- 时基：递增-递减模式 (TB_COUNT_UPDOWN)，TBPRD = TBCLK/(2×10kHz)
- 死区：DB 模块，死区时间 200ns（可调）
- 移相：通过 TBPHS 寄存器实现模块间移相，映射 D1/D2 到实际相移值
- 影子寄存器：CTR=0 时装载，避免 PWM 毛刺

## 5. ADC 采样

| 通道 | 信号 | 用途 | 说明 |
|------|------|------|------|
| ADCINA0 | V2 | PID 反馈 + 计算 k | 输出电压（底板电阻分压后） |

- V1（400V）固定，作为编译常量，不采样；k = V1 / (n · V2)
- 触发方式：ePWM1 SOCA 触发，在 PWM 周期中点采样（避开开关噪声）
- 采样率：10kHz（每个 PWM 周期），控制计算先用 IIR 滤波再送入 PID 和 DPS

## 6. 软启动

- 方式：电压给定从 0 斜坡上升至目标值
- 可配置斜坡时间（默认 100ms，范围 10ms~5s）
- 斜坡步进：每个控制周期（1ms）递增
- 斜坡期间 DPS 算法正常工作，D1/D2 自然从 0 增长

## 7. 保护逻辑

| 保护项 | 阈值（默认） | 动作 | 恢复方式 |
|--------|-------------|------|----------|
| 输出过压 | >120V（120% 额定） | 立即封所有 PWM（TZ 模块触发） | Modbus 写清除故障 |
| 输出过流 | >15.0A | 同上 | Modbus 写清除故障 |

- 保护判定：连续 3 次采样超阈值才触发（抗尖峰干扰）
- 故障锁存：进入 FAULT 状态，LED 指示故障类型
- TZ 模块：使用 TZ1 (GPIO12) 硬件触发，单周期内关断 ePWM1~4

## 8. 系统状态机

```
         ┌──────────┐
    ┌───→│   IDLE   │←─── Modbus 停机命令
    │    └────┬─────┘
    │         │ Modbus 启动命令
    │    ┌────▼─────┐
    │    │SOFT_START│ 斜坡中可被停机打断
    │    └────┬─────┘
    │         │ 斜坡完成
    │    ┌────▼─────┐
    │    │ RUNNING  │──→ 检测到故障 ──→ ┌───────┐
    │    └──────────┘                    │ FAULT │
    │         ↑                          └──┬────┘
    │         │         Modbus 清除故障      │
    │         └─────────────────────────────┘
    │
    └── 任何状态均可接受停机命令回到 IDLE
```

| 状态 | 值 | 说明 | PWM | LED5 |
|------|---|------|-----|------|
| IDLE | 0 | 等待启动命令 | 封锁 | 灭 |
| SOFT_START | 1 | 电压给定斜坡上升 | 运行 | 慢闪 (500ms) |
| RUNNING | 2 | 正常稳压运行 | 运行 | 常亮 |
| FAULT | 3 | 故障锁存 | 封锁 | 快闪 (100ms) |

### 12.1 模块依赖关系

```
app ──→ control ──→ drivers
  │        │
  ├─→ protection ──→ drivers
  │        │
  ├─→ protocols ──→ drivers
  │
  └─→ bsp
```

- **app** 是顶层调度者，依赖所有下层模块
- **control** 执行控制算法，依赖 bsp（systick）和 drivers（ADC/PWM）
- **protection** 独立运行，直接读取 ADC 并控制 TZ 模块
- **protocols** 依赖 drivers（SCI），与 Modbus 主站通信
- **bsp** 为最底层，提供时钟和延时基础服务
- **include** 被所有模块引用，存放共享定义
