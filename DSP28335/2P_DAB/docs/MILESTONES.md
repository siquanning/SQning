## 第2片：ePWM 4路输出 + 死区  ✅

**目标**：8 路 PWM 门极信号正确输出。
**状态**：代码完成，7/8 路波形验证通过。GPIO2 波形异常（底板硬件，非代码问题），待排查。

- [x] SysConfig 配置 ePWM1~4（GPIO00~07），递增-递减模式，10kHz
- [x] DB（死区）模块，200ns 死区
- [x] 互补输出（S1/S2、S3/S4、Q1/Q2、Q3/Q4 反相 + 死区）

- [x] TBPHS 相移机制就位（为第4片预留接口）

**可验证**：示波器看 8 路 PWM 波形，频率、死区、互补关系正确。
**未关闭**：GPIO2 (ePWM2A) 直角梯形 → 见 notes/troubleshooting.md 问题10。

## 第3片：ADC 采样 + IIR 滤波 ✅

**目标**：能读到 V2 电压，数值可信。
**状态**：代码完成，待硬件验证。

- [x] SysConfig 配置 ADCINA0（代码直接寄存器操作，未用 SysConfig）
- [x] ePWM1 SOCA 触发，CTR=0 周期中点采样（避开开关噪声）
- [x] 一阶 IIR 低通滤波（fc ≈ 100Hz @ fs=10kHz，alpha=0.061）
- [x] 计算 k = V1 / (n × V2)，V1=400V 固定，n=4
- [x] ADC 校准与量纲转换（ADC_V2_SCALE=66.67, 3Vref/4096）

**可验证**：调试器查看 `g_adc` 结构体（raw, v2_raw, v2_filtered, k），万用表对比。
**待验证**：上电后 ADC 采样值是否准确，IIR 滤波效果，k 值合理性。

## 第4片：DPS 算法移植  ✅

**目标**：给定 p0 和 k，算出正确的 D1/D2，并映射到 ePWM 相移。
**状态**：代码完成，开环示波器验证通过（p0=0.3, k=0.8, D1=0.1546, D2=0.0939, S1→Q1≈7.7µs 与理论一致）。

- [x] `dps_compute()` 移植到 DSP（float + FPU 浮点运算）
- [x] `dps_modulation_signals()` 移植
- [x] D1/D2 → TBPHS 相移值映射函数（`dps_update_epwm` + `epwm_set_phase`）
- [x] 开环测试：手动给 p0 和 k，验证 ePWM 相移变化 — 示波器验证通过

**可验证**：固定 p0=0.5, k=1，示波器测 S1 和 Q1 之间的相移与理论值一致。

## 第5片：PID 控制器 + 闭环稳压  ✅

**目标**：V2 电压能自动跟踪 V2_ref，稳定在设定值。
**状态**：代码完成，4 项全部实现，待上功率级验证 V2=50V 闭环。

- [x] PID 控制器实现（1kHz 控制频率，与 systick 同步）
- [x] PID 输出限幅 [0, 0.999]
- [x] 闭环联通：V2_ref → PID → p0 → DPS → PWM → 功率级 → V2 → ADC → PID
- [x] PID 参数可在线修改

**可验证**：带轻载，设 V2_ref=50V，示波器看 V2 是否稳定在设定值。

## 第6片：软启动 + 状态机  ✅

**目标**：系统有四态切换能力，启动时电压平滑上升。
**状态**：代码完成，编译通过，待功率级上电验证。

- [x] 状态机实现：IDLE(0) → SOFT_START(1) → RUNNING(2) → FAULT(3)
- [x] V2_ref 斜坡发生器（默认 100ms，可配置 10ms~5s）
- [x] 斜坡期间可被停机打断
- [x] LED5 状态指示（灭/慢闪/常亮/快闪）

**未验证**：待功率级上电后实测斜坡波形和 LED5 行为。
