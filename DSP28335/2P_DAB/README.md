# 2P_DAB — DAB 电源控制系统

基于 TI TMS320F28335 的双有源桥（DAB）电源控制系统。

## 目录结构

```
.
├── docs/                  # 产品文档（PRD、需求记录、关键决策）
├── assets/
│   ├── design/            # 设计效果图、UI 参考
│   ├── bug/               # 测试报错截图
│   └── reference/         # 参考图、灵感收集
├── notes/                 # 学习笔记、踩坑记录、技术方案
├── AGENTS.md              # AI 开发助手指南
└── README.md              # 本文件
```

## 开发环境

- **IDE**: TI Code Composer Studio (CCS)
- **编译器**: TI C2000 Compiler
- **配置工具**: SysConfig
- **调试工具**: CCS Debug Probe
